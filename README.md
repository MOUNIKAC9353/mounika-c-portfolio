# Mounika C — Personal Portfolio

Starter portfolio for a Java Developer / future Java Full Stack Developer.

## Run locally
1. Open `index.html` in a browser, or use VS Code Live Server.
2. Add your professional profile photo as `assets/profile.jpg`.
3. Add your actual resume PDF as `assets/resume.pdf`.
4. Update the GitHub and LinkedIn URLs if needed.
5. Later we can connect the contact form and Java project backend.
